Instal FASTSONG PWA (Progressive Web App)

FASTSONG tidak memerlukan instalasi seperti aplikasi pada umumnya. Anda dapat menginstalnya sebagai PWA, menjadikannya berjalan seperti aplikasi native di perangkat Anda.

✔ Bisa digunakan offline ✔ Lebih cepat diakses ✔ Tampil seperti aplikasi ✔ Hemat penyimpanan

Cara Install di Android / Chrome

  1. Buka https://fastsong.eu.org
  2. Klik ikon Install App di bagian address bar Chrome
  3. Pilih Add to Home Screen

Cara Install di iPhone (Safari)

  1. Buka web FASTSONG menggunakan Safari
  2. Klik ikon Share
  3. Pilih Add to Home Screen

Cara Install di PC / Laptop

  1. Buka FASTSONG melalui Chrome
  2. Ikon Install akan muncul di address bar
  3. Klik dan pilih Install
